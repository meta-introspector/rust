# Orchestra of Rust Models: Prime Generator Sampling

## Model Architecture
Each model uses prime^n generators to sample the entire usage_data:
- **2^n models**: Binary decision trees
- **3^n models**: Ternary logic systems
- **5^n models**: Quintic algebraic structures
- **7^n models**: Septenary recursive patterns
