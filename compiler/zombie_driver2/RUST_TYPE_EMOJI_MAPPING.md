## 🎨 Usage in Tapestries

These emojis are used in our tapestry generation system to create
visual representations of Rust code character. Each type gets mapped
to its corresponding emoji based on:

- **Frequency**: How often it appears in the codebase
- **Complexity**: Mathematical complexity score
- **Curve Class**: Mathematical curve classification
- **Category**: Semantic category in Rust
